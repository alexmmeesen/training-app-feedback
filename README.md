# Training app feedback

Feedback from the Training app: bugs, ideas and things that look off. Anyone with a GitHub account can open an issue.

The easiest way is the feedback button at the top right of any screen in the app: it fills in the screen, the app version and the phone for you. You can also open an issue here directly.

The app's code lives in a separate private repository. Please don't post personal or health data here: issues are public.
